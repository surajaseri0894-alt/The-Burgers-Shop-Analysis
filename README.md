#  Burger Shop project overview

This project is an interactive Excel Sales Dashboard designed to analyze burger shop sales performance, customer ordering behavior, and category-wise revenue trends. The dashboard converts raw transactional data into meaningful business insights using data cleaning, KPI tracking, pivot tables, and interactive visualizations.

The main objective of this project is to identify sales trends, monitor product performance, analyze customer purchase behavior, and support better business decision-making through data-driven reporting.

---

##  Project Overview

The dashboard provides a complete overview of sales performance by tracking:
- Total revenue generated
- Total customer orders
- Average order value
- Monthly sales trends
- Top-selling products
- Sales contribution by categories
- Weekday vs Weekend sales performance
- Time period-based customer activity

Interactive slicers allow dynamic filtering and improve user experience for data exploration.

---

##  Data Preparation

The raw datasets were cleaned and transformed before building the dashboard.

###  Data Cleaning & Transformation
- Cleaned and transformed raw datasets
- Removed null and unwanted records
- Merged menu pricing with order transaction data
- Applied proper data types and currency formatting
- Standardized date and time formats

###  Calculated Columns Created
- **Day Name** → Identifies day-wise sales performance
- **Workday Type** → Categorizes sales into Weekday and Weekend
- **Time Period** → Segments orders into Morning, Afternoon, Evening, and Night
